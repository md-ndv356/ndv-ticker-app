# Rich Text Editor Module - NDV Ticker App

## 概要
NDVティッカーアプリ用リッチテキストエディター。Minecraft Raw JSON形式のようなセグメント方式でテキスト管理を行う高度なテキストエディターシステム。

## ファイル構成

### コアファイル
- `rich-text-editor.js` - メインエディターロジック
- `text-manager.js` - TextManagerクラス（セグメント管理）
- `rich-text-editor.css` - エディター専用スタイル
- `index.html` - エディターUI

## TextManager仕様

### データ構造
```javascript
// セグメント形式（Minecraft Raw JSON類似）
{
  segments: [
    {
      type: 'text',
      content: 'サンプルテキスト',
      styles: {
        bold: true,
        italic: false,
        underline: false,
        color: '#FF0000'
      }
    }
  ]
}
```

### 主要メソッド
```javascript
class TextManager {
  // スタイル適用
  applyStyle(start, end, styleType, value)
  
  // スタイル削除
  removeStyle(start, end, styleType)
  
  // テキスト挿入
  insertText(position, text)
  
  // テキスト削除
  deleteText(start, end)
  
  // HTML変換
  toHTML()
  
  // プレーンテキスト取得
  getPlainText()
}
```

## Rich Text Editor仕様

### 主要機能
1. **リアルタイムスタイリング** - テキスト選択中の即座のスタイル適用
2. **キーボードショートカット** - Ctrl+B/I/U対応
3. **カラーピッカー統合** - リアルタイム色変更
4. **DOM同期** - TextManagerとDOMの完全同期
5. **スタイル重複処理** - 複数スタイルの適切な管理

### キーボードショートカット
```javascript
// サポート済みショートカット
'Ctrl+B' | 'Cmd+B'  // 太字切り替え
'Ctrl+I' | 'Cmd+I'  // イタリック切り替え
'Ctrl+U' | 'Cmd+U'  // アンダーライン切り替え
```

### API仕様
```javascript
// エディター初期化
const editor = new RichTextEditor(container, options);

// データ読み込み
editor.loadData(textManagerData);

// データ取得
const data = editor.getData();

// イベントリスナー
editor.on('change', (data) => {
  // テキスト変更時の処理
});
```

## 統合仕様

### setting モジュールとの連携
```javascript
// 初期化メッセージ受信
window.addEventListener('message', (event) => {
  if (event.data.type === 'INIT_EDITOR') {
    editor.loadData(event.data.data);
  }
});

// 保存データ送信
function saveAndClose() {
  window.parent.postMessage({
    type: 'EDITOR_SAVE',
    data: editor.getData()
  }, '*');
}
```

### データ永続化
- **LocalStorage**: 一時保存機能
- **PostMessage**: 親ウィンドウへのデータ転送
- **JSON形式**: 汎用性の高いデータ形式

## 既知の制約・注意点

### 制約事項
1. **ネストスタイル**: HTMLのネストした構造は非対応
2. **フォントサイズ**: 現在は色・装飾のみサポート
3. **画像埋め込み**: テキストのみ対応

### パフォーマンス注意点
1. **大容量テキスト**: 10,000文字以上で若干の遅延
2. **リアルタイム更新**: 高頻度の変更で一時的な負荷
3. **メモリ使用量**: 長時間使用時の定期的なクリーンアップ推奨
