# Settings Module - NDV Ticker App

## 概要
NDVティッカーアプリの設定画面モジュール。リッチテキストエディターの統合やモーダル表示を管理する。

## ファイル構成

### メインファイル
- `index_new.html` - モダンな設定画面UI（現行版）
- `style_new.css` - 設定画面のスタイル（glassmorphism対応）
- `settings-manager.js` - 設定管理とリッチテキストエディターとの連携

### レガシーファイル
- `index.html` - 旧設定画面（参考用）
- `style.css` - 旧スタイル（参考用）

### 設定・テスト用
- `config-structure.js` - 設定構造の定義
- `test-modal.html` - モーダル表示のテスト
- `rich-text-editor-design.md` - リッチテキストエディターの設計文書
- `preload.js` - Electron preloadスクリプト

## 主要機能

### 1. リッチテキストエディター統合
- ティッカーテキストのリッチテキスト編集
- モーダル形式でエディターを開く
- テキストの保存・キャンセル機能
- postMessage APIによる親子ウィンドウ間通信

### 2. UI/UX設計
- **デザインシステム**: Glassmorphism + 自然な日本語UI
- **カラースキーム**: ダークテーマベース
- **レスポンシブ**: モバイル・デスクトップ対応
- **アニメーション**: CSS transitionによるスムーズな遷移

### 3. 設定管理
- ティッカーテキストの管理
- プリセットとカスタマイズの切り替え
- リアルタイムプレビュー

## API仕様

### postMessage通信
```javascript
// エディターにデータを送信
window.postMessage({
  type: 'INIT_EDITOR',
  data: {
    content: [
      { type: 'text', content: 'サンプルテキスト', styles: {} }
    ]
  }
}, '*');

// エディターから保存データを受信
window.addEventListener('message', (event) => {
  if (event.data.type === 'EDITOR_SAVE') {
    const data = event.data.data;
    // データを処理
  }
});
```

## 技術仕様

### フロントエンド
- **HTML5** + **CSS3** + **Vanilla JavaScript**
- **Glassmorphism Design** - 透明度とぼかしを活用したモダンUI
- **CSS Grid/Flexbox** - レスポンシブレイアウト
- **CSS Variables** - テーマ管理

### エディター連携
- **Window API** - 子ウィンドウとしてエディターを開く
- **postMessage** - 安全なクロスウィンドウ通信
- **データ永続化** - localStorage + メモリ管理
